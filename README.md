# DTAhub Website

Official app store website for DTAhub apps.

## Tech Stack
- Frontend: HTML + Tailwind + Alpine.js
- Backend: Node.js + Express
- Database: Supabase (PostgreSQL)
- Storage: Cloudinary
- Hosting: Railway

## Setup
1. `npm install`
2. Copy `.env.example` to `.env` and fill credentials
3. `npm start`
